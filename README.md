# AFMPC

Project website for **Underwater Visual Target Tracking with Target-Specific Depth Estimation and Adaptive Model-Fusion Predictive Control**.

- Website: https://fpj-gaoge.github.io/AFMPC/
- Paper: https://arxiv.org/abs/2609.20731

The site presents the tracking task, method, real-pool demonstration and experimental results. It uses plain HTML, CSS and JavaScript, with no build step or third-party runtime dependencies.

## Local preview

```sh
python -m http.server 4173
```

## Deployment

GitHub Pages serves the root of the `main` branch. The `.nojekyll` file enables direct static-file publishing.

Paper figures and demonstration footage are research materials supplied for this project. The opening diagram is a conceptual task illustration, not experimental data.
